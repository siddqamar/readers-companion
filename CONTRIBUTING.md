# Contributing to Reading Logs

Thanks for your interest in contributing to Reading Logs ❤️

This project is focused on making online reading easier to capture, organize, and retain through a frictionless Notion workflow.

Whether you want to:

- fix a bug
- improve the UI
- optimize performance
- improve the reading workflow
- suggest ideas

you are welcome here.

---

# Before You Contribute

Please:

- Check existing issues before opening a new one
- Keep pull requests focused and clean
- Test your changes before submitting
- Follow the existing minimalist UI and code style

---

# Development Principles

Reading Logs is intentionally built around:

- Minimal friction
- Fast interactions
- Clean UI
- Simple workflows
- Lightweight architecture

Avoid:

- unnecessary dependencies
- over-engineering
- unrelated refactors inside feature PRs

---

# Commit Message Examples

```bash
feat: add screenshot preview support
fix: resolve highlight sync issue
ui: improve popup spacing
docs: update README
```

---

# Reporting Bugs

When opening an issue, try to include:

- steps to reproduce
- expected behavior
- actual behavior
- screenshots if relevant

---

# Feature Requests

Feature ideas are always welcome.

Please explain:

- the problem
- why it matters
- your proposed solution
